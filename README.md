# AI-Assisted Website Development Project
This repository includes a simple website built using VS Code, HTML, and CSS. The page descriptions were generated by VS Code's AI assistant. The purpose of this repository is to instruct IT 104 students on how to develop and deploy a website to GitHub Pages, and document in Markdown.
The instructions are located on the Documentation tab in the website. Go to the site link below to access it. 

# Purpose
* Teach IT 104 students how to build a website using VS Code and its AI assistant.
* Teach students how to code using HTML and CSS.
* Showcase hobbies, projects or side businesses on a website.
* Practice basic web development with AI assistance and debugging.
* Deploy a live website to a cloud environment (Github Pages).
* Document the project in Markdown.

# Technologies Used
* HTML
* CSS
* VS Code and its embedded Copilot AI assistant
* Git and Github Pages
* Markdown markup language
